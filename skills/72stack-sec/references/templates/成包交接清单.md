# 成包交接清单（挖洞 → 复现成包）

> 挖洞 skill（72stack-sec）落盘的 `报告/*.md` 要能直接交给成包/复现角色，**禁止**缺头回炉。  
> 正文八块仍只认 `~/.grok/rules/vuln-report-format.md`。本清单是交接契约。

## 路径

- 任务根：`D:\SRC挖洞\{项目}_SRC挖洞\`（桌面同名是联接）
- 报告：`D:\SRC挖洞\{项目}_SRC挖洞\报告\` 扁平包（`gen_report.py` + 成对截图 + docx；旁侧可有同名 `.md` 洞源）
- **禁止**把报告 md/docx 挪到 `D:\SRC工作区\docs\`

## md ready-for-pack（挖洞侧落盘前自检）

- [ ] 复现步骤有「请求包说明」：可直接贴进 Burp Repeater，只换 Cookie
- [ ] 每个关键请求块含：请求行、`Host`、`Accept`（或实测）、`User-Agent`、有则 `Referer`/`Origin`、`Connection`；有 body 则 `Content-Type` + body
- [ ] **禁止**请求侧 `…`/`...` 省略到无法粘贴
- [ ] Cookie：有会话写完整实值（format 要求）；未登录不写 Cookie 并在说明里写清
- [ ] 响应摘要可另附成包材料；挖洞 md 步骤里仍不贴回包（听 format）
- [ ] 影响原图：能看见图须留原图不打码；关键步骤默认 `*_burp.png` + `*_browser.png` 成对
- [ ] 禁词：不要写「Burp 复测成立」「（原始截图）」「测试日期 YYYY-MM-DD」
- [ ] 跑闸：`python scripts/report_format_check.py --ready-for-pack --dir "D:\SRC挖洞\{项目}_SRC挖洞\报告"`

## 和成包 skill 的分工

- 挖洞侧：按 format 写可验证 md + 实拍证据路径齐
- 成包侧：磁力聚星密度 docx、双截图排版、Cookie 占位（若平台要求）等
- 缺 Host/UA/成对证据 → **不准**标可成包，回挖洞侧补，不在成包侧猜头
