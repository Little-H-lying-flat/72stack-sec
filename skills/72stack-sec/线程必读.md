## 本轨=未登录

主业：§4.0 → JS 到 `js/{host}/anon/` → 未登录例外 + 有差分面四件套 + 认证口清单。打开是登录页：找业务 API + 发码/提交 API。看见登录页不是换资产。

DONE → `{dig}/{host}/DONE_anon.md`。清单 → `endpoints.md` + `matrix.md`。

**必写缺号行：**

`缺号：干净|放弃|无HTTP口；发码=<METHOD URL或无>；提交=<METHOD URL或无>；通道=sms|email|无；sid=<或无>；盾=无|滑块|实名|SSO；原因=…`

- **要发码 ≠ 放弃。** 发码/提交 API 写 METHOD+完整 URL，标干净。
- **登录页 URL 不是干净口。** 抠不出 API → `无HTTP口`。滑块/实名/别人的 IdP 本身 → `放弃`（盾写入缺号行即可；**肥面入库由主控**写 `资产/人工过盾续挖.md`，线程不改该文件）。
- 禁止写 cookie、禁止假装有会话、禁止写 `DONE_auth`。
- 瘦壳一眼证伪即可。肥面有干净口：写缺号行，**禁止**自己标 covered。

## 本轨=有会话

spawn 会带 cookie 路径和身份（有店铺|空户|待确认）以及半径（单户|可换户|疑似跨租户|未知）。用法：`curl -b {dig}/{host}/session.cookie`；仍 109 把 name=value 拼 `Cookie:` 头。禁止再发码。

**换票 result=1 ≠ 有业务身份。** spawn 写「空户」或「待确认」→ 第一枪打身份口；仍空则打资质/开通跳步，不要对着 109 换 id。写「有店铺」→ 对象图/换 id。

主业：先读 `js/{host}/anon/`；带着本 sid cookie GET 业务首页，只补新 chunk 到 `js/{host}/{sid}/`。懒加载文件名在主包里，**禁止靠点菜单当抽干**。路由表 / hidden path 没画在页面也直接打 API。细节 `知识库/js-reverse-guide.md`「登录后懒加载」。§4.0 用这批包说清这摊。spawn 写了「有号挖」时未登录例外仍点；默认挖X 未登录轨已点过则不必重复。

DONE → `{dig}/{host}/DONE_auth.md`。清单 → `endpoints_auth.md` + `matrix_auth.md`。必写 `身份=有店铺|空户` + `半径=单户|可换户|疑似跨租户|未知` + `资质口=<METHOD URL或无>`。半径未知且空户 → 只打资质/开通，不要换 id。禁止写缺号行催新号。
