# 回灌闭环（发现引擎怎么变强）

> P3 操典。目标：每次命中/漏报都变成**下一站会多问的一句话**，而不是堆报告收藏。
> 禁止在本文件或盲区库写利用步骤 / PoC / 敏感实值。

## 一条闭环长什么样

```
本站 suspects 提出语义疑问
  → 确认命中或明确漏报
  → 追加 知识库/semantic-blindspots.md 一行（或 auto-safe 写入 semantic-blindspots.auto.md）
  → 提炼进「高频问句速查」（若是新根因）
  → 新任务威胁模型头：从盲区库挑相关问句拷进 suspects
  → 同一根因 ≥2 次 → 开 D:\dsh-72stack-sec\rules/hunt-iter.md 评估是否进打穿短表
```

## 谁在什么时候写

| 角色 | 触发 | 必做 |
|------|------|------|
| 线程 | 打成中危+ 或明确「该问没问」 | DONE/回单写一句「建议主控回灌：…语义疑问…」 |
| 主控 | 收中危+ 报告 / 收漏报声明 | **同回合**确认盲区主表或 `.auto.md` 已有对应行；suspects 头引用；covered 前核对 |
| 主控 | 新站开 suspects | 扫盲区库「业务·栈」相关 + 高频问句，写入威胁模型头 |
| 任何人 | 根因重复 2+ | 只开 hunt-iter 候选，**不直接改**打穿短表 |

## 盲区库一行最低质量

- 语义疑问必须是**服务端信什么 / 哪道防线假的**，不是 payload。
- 对象形态写参数形态（如 `detail?id=`），不写真实 id 值。
- `回灌动作` 先填 `已写入 suspects 复盘` 或 `待 hunt-iter`。
- `任务指针` 用短名/报告标题，勿贴 cookie/账号。

## covered 前主控自问（P3 门闩）

1. 本站有中危+ 报告？→ 盲区主表或 `semantic-blindspots.auto.md` 是否已有对应新行？
2. 本站明确漏报？→ 是否已追加「漏报」行，并补进本站 suspects 补丁节？
3. 新开的 suspects 威胁模型头是否至少引用了 1 条相关盲区/高频问句（或写 N/A + 原因）？

任一条「该做却没做」→ **禁止**把本站写入 `covered_hosts`。

## 和硬闸的关系

- `suspects_coverage_check.py`：管「有没有 suspects / 覆盖率勾选」。
- 本操典：管「有洞/漏报之后记没记进引擎记忆」。
- 两者都过，才算发现引擎跑通，而不是只交了报告。

## 发现进化环（**工作流必跑** · 不替代本操典）

主控收单 / `p2_gate`（默认挂载）/ `mark_covered` **必触发**（执行腿禁止）：

- `scripts/evolve_hook.py --host-dir|--task-root` → 一键 episode + propose → 任务根 `进化/`
- 拆步：`episode_from_done.py` / `evolve_propose.py` / `evolve_apply.py`
- `--auto-safe`（hook 默认）：只追加同目录 `semantic-blindspots.auto.md`，**不改**本主表、不改 rules/短表/调度

说明见 `进化/README.md` + `主控调度.md`「收单必跑发现进化环」。**auto 行 ≠ suspects 头已引用**；covered 门闩不因进化环免除。hunt-iter / 短表仍人审。

## 令牌类强制回灌（P1）

涉及以下对象的中危+ 命中或明确漏报 → **同回合**必须追加盲区库一行（勿写实值/利用步骤），并在该站 suspects 引用高频问句「令牌绑谁 / 能到哪 / 跨租户墙」之一：

- cookie / `*_st` / `_ph` / passToken / 刷新票
- OIDC / SSO 回调票 / 自定义身份头当会话
- 会话仓、多 sid 换票
- `tenantId` / `shopId` / `Account-Id` 等租户键跨主体差分

缺盲区行或 suspects 未引用 → **禁止** `covered_hosts`。
