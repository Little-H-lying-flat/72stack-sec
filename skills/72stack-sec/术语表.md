## 测绘与节奏

| 词 | 释义 |

|----|------|

| **锁面** | 本任务允许挖的资产边界（SRC 公告 + 股权闸）。出圈不深挖。 |

| **自由跳** | 在锁面内可跟业务流跳 host；不是只能打用户粘的第一条 URL。 |

| **一种子闭环** | 一轮只搜/挖**一个**根域种子：FOFA → 去废去非存活 → leftover 活面挖完 → 标 done → **立刻**下一条 pending。禁止多种子一次搜完再挖。 |

| **回灌** | 从已挖 host 业务流带出的新根/新面，写入种子队列 pending；本种子 leftover 挖完才搜。 |

| **leftover** | 本种子 FOFA 清洗后仍待挖的活面清单。未空禁止换种。 |

| **FOFA 0 NEW** | 本词测绘清洗无新活面。按 leftover 真空：有 pending → 同回合 `NEXT: 下种子`，禁止干等翻页。 |

| **leftover 真空** | 本种子**已首扫清洗**且活面 pending/doing=0（或 0 NEW）。待入库/未 FOFA ≠ 真空。真空 ≠ 少补席；有 pending → 同回合 `NEXT: 下种子`。 |
| **leftover done** | 该 host **本轨交单**，不是 covered、不是种子收口。禁止用 leftover done 条数当进度。 |
| **收口债** | `编排/收口债.md`（脚本生成）：登录轨 / 过盾 waiting·offered·timeout / 升链 / 小程序待打开。**不挡**本种子翻页。有 cookie 无 DONE_auth、升链 pending、无盾干净口、小程序 cached 未解、login ready 未派 → 主控同回合必须动，不是翻页替代。 |
| **小程序队** | `资产/miniprograms.md`。测绘不占席、不挡翻页。状态 skip/pending_triage/waiting_open/cached/unpacked/in_leftover。waiting_open+锁面=是 → 人在微信打开；cached → 收单 CLI 解包抽 URL 进 leftover。禁止 CDN 拉包、禁止全网爬微信。 |
| **僵尸席** | leftover 表行 `doing`，但无新进度。有 dig/js/jsonl：**默认 45 分钟**冻结；从未落盘：**默认 25 分钟**（heartbeat）。`seat_recycle.py` 回收：doing→pending、seats 清 idle。不杀进程。占席只认 seats.md；回收后允许同 host 再派。僵尸不挡补席/翻页。 |

## 面与席

| 词 | 释义 |

|----|------|

| **肥面** | 值得深挖的业务面（有结构、有发码/提交口、有对象图潜力）。 |

| **瘦壳** | 一眼证伪的空站/同皮/欢迎页/纯网关；证伪即可，不占满矩阵。 |

| **同皮 / sibling** | 与已挖站同构的镜像面；差分一眼，无新 path 则停。 |

| **席 / 占席** | 并行未登录或有会话线程槽位。上限默认 10（书面授权可超）；**目标席数**默认等于上限（用户书面指定 N 则改）。空席合法仅当无可派，不是完工条件。 |
| **目标席数** | 同时占席要维持的数量。有可派必须补到目标。禁止等最后一条 doing 交单再整波开席。 |
| **本种子翻页** | leftover pending 填不满空席 → 同回合 FOFA 本种子下一页补池。doing>0 不挡翻页。≠ 下种子（#4 真空才换种）。 |
| **升链席** | 中危+ 落盘后另开的溢出席（`本轨=升链`）。不计入目标席数；默认同时 1 条（用户可指定上限）。只跟同一报告对象升到能看别人 / 接管差一步 / sink 差分或证伪。禁止真写、禁止凭据进业务、证明即停。不挡 leftover 保满。 |
| **升链队列** | `编排/升链队列.md`。原轨交 `升链对象=` 入队后可换站。队列非完成/证伪 → 该站禁 covered。 |
| **登录旁路 / login_lane** | 有盾进号的人在环旁路：等登录 + 有会话深挖。**永不计入目标席数 10**（与升链同级溢出）。真源仍是 `资产/人工过盾续挖.md`；运行时 `编排/login_jobs.jsonl` + `login_offer.md`。脚本 `login_gate.py`。执行腿禁止跑。 |
| **auth_wait** | 登录旁路「等人」态：`offered` 已要约、倒计时中。同时最多 `login.wait_max`（默认 1）。不占 seats.md 1–10。超时 → `timeout`，不空转。 |
| **auth_exec** | 登录旁路「有会话深挖」席：cookie 已 ready 后 spawn `本轨=有会话`。同时最多 `login.exec_max`（默认 2），**默认不计入目标席数 10**。batch 在 `编排/_auth_spawn_batch.json`，与 `_spawn_batch.json` 分离。 |
| **login_job** | `编排/login_jobs.jsonl` 一行：host/family/priority/deadline/state。终态：`queued`\|`offered`\|`ready`\|`timeout`\|`skip`\|`no_account`\|`done`\|`fail_shield`。 |
| **offered** | 过盾表/job 状态：已向人发出登录要约（`login_offer.md`），deadline 内等 cookie。 |
| **timeout（登录）** | 要约到期无人交 cookie。回冷却（默认 6h 内不再 offer）；≠ `skip`（你明确没号）。不挡 10 席未登录保满。 |
| **no_account / skip（登录）** | 人明确无号或放弃本 host 进号；登录轨 N/A，不反复要约。 |

| **一眼轨** | 未登录浅挖：探活 + 未登录例外 + 抠发码/提交，不跑全矩阵。 |

| **JS=已抽** | 肥面：anon（及登录轨）JS 已落到 `js/<host>/anon/`，且 path 进了 `endpoints*`/`suspects`（备注来自 JS），或明示「JS 无业务 API」。只「已拉 JS」不算。 |

| **JS=N/A瘦壳** | 瘦壳证伪：无 JS 清单义务；DONE 写此字段即可过 `js_inventory`。 |

| **JS进清单** | 闸：`js_inventory_check` — anon 有 `.js` 却清单空且未声明无业务 API → FAIL（假抽）。 |

| **清单全静态** | 已写 `JS=已抽`/来自 JS，但行全是静态壳、无业务 METHOD path、也未声明「JS 无业务 API」→ 假抽变种，`js_inventory` FAIL（证据包 17）。 |

## 认证与过盾

| 词 | 释义 |

|----|------|

| **干净口** | 可自动化进号的 HTTP 发码/提交 API（非仅登录页 URL）。 |

| **缺号行** | DONE 里记录「缺号：kind / 盾= / 发码= / 提交=」的行，供主控进号。 |

| **盾** | 滑块/图形/实名/别人的 IdP 等；写入缺号行。 |

| **人工过盾续挖** | 肥面有盾时入库的人过盾队列表。状态机：`waiting`→`offered`（gate 要约）→人交 cookie→`ready`→`doing`→`done`；旁路：`timeout` / `skip` / `no_account`。运行时由 `login_gate` 驱动，表仍是真源。 |

| **ready** | 过盾表状态：本地已有可用 `session.cookie`，主控须插 **auth_exec** 有会话旁路 / `NEXT: 有会话`（可写在 `_auth_spawn_batch` 或 NEXT）。 |

| **waiting** | 过盾表状态：等人过盾、尚未要约；**禁止**空 cookie 开登录轨。gate 可提升为 `offered`。 |

| **空 cookie 登录轨** | 无会话却 spawn「有会话」线程；禁止。≠ 禁止对无盾干净口跑 `auth_flow`。 |

| **身份一枪** | 进号后先打 `/me` 类确认业务身份（店铺/计划/门店），再对象图。 |

| **空身份禁写** | 换票成功但业务身份空 = **假点**；写面只能标此并停枪，禁止当已打穿喷矩阵。 |

## 证明与假点

| 词 | 释义 |

|----|------|

| **差分** | 相对基线（自己的 total/列表/身份）多出来的**别人的**东西；打穿的唯一判据。回 200 不算。 |

| **差分指回** | 收工/covered/凭证/越权结论必须引用 `diff.json#D-xx`（或等价 id）。 |

| **执行信号** | RCE 收工必须有的可复现差分：约定标记文件 / 约定 stdout / 约定进程名等；仅 Sink 词、口头「执行了」、沙箱 `uid=`、upload-only / pollution-only / parse-only / schema-only 半条链不算。闸：`rce_exec_signal_check`。 |

| **注入差分信号** | SQL 注入 covered 必须有的业务差分：total/条数变化、他主体字段、对照无注入失败；仅喷引号、语法错、sqlmap 日志、WAF 405 不算。闸：`sqli_diff_signal_check`。 |

| **认钥闸** | 抄到云钥/令牌不算洞；生产侧认钥（假值对照 + 只读身份一枪）过了才写。禁止认钥后继续列桶/改配。 |

| **假点** | 看起来像洞其实不是：只出自己的数据、游客空号、模型口头执行但对不上本机、ES 不吃这段 SQL 等。假点 → 不报 / 换打法。 |

| **同闸** | 多 path 撞同一登录/鉴权墙；无新差分则停，禁止对着同一拦截码反复磨。 |

| **禁 covered** | 本站未达收口条件（含 p2 FAIL、肥面未进号、缺差分指回等）时**禁止** `mark_covered`（禁手写 `covered_hosts`）。只卡本站≠整场停。 |

| **covered** | 本站未登录/双轨收口完成、经 `mark_covered.py` 写入 `covered_hosts` 后不 reseat。旧 covered 无 `DONE_auth` 可翻回补登录轨。 |

## 编排续航（闸）

| 词 | 释义 |

|----|------|

| **NEXT** | 闸动作三选一：`补席` \| `下种子` \| `人工过盾`（续挖同义可 `有会话`）。「NEXT: FOFA…」是步骤说明不是闸动作。 |

| **无 NEXT = 编排 bug** | 纯文本「本波收口/整场停」且无 NEXT；或队列仍有 pending 却无「下种子」。不是「站没了」。 |

| **p2 FAIL** | `p2_gate` 未过 → **禁本站 covered**，且必须有 NEXT；不是整场停。 |

| **打穿短表** | 手法索引：认什么 / 打哪 / 出什么算成 / 假点；禁止当百科通读。 |

| 词 | 释义 |

|----|------|

| **CORS 不挖** | 不测 CORS 配置类面。 |
