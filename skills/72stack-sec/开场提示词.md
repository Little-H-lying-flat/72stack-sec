# SRC 开场提示词（复制即用）

> 用法：把 `{目标}` / `{短名}` 换成集团或品牌；整段丢给 Agent。  
> 只走本 skill + `~/.grok/rules`。禁 `/hack`、`src-hunter`。  
> 立法冲突以 `~/.grok/rules` 为准。  
> 双轨调度 / 进号闭环只认 `主控调度.md`；约束测试红线只认 `SKILL.md` 该节。本文件只给可复制整段。  
> **默认 `挖X` = 流水线双轨**（未登录先铺，进号成功再插登录轨）。  
> **`有号挖` = 登录轨优先**（文末那段）。**`只未登录` / `没号挖` = 不开登录轨。**

## 自由跳（模糊目标 / 只给集团名）

```text
挖{目标}

只走 ~/.grok/skills/skill + ~/.grok/rules。
禁 /hack、src-hunter。
立法只认 ~/.grok/rules（dig-scope / src-value / vuln-report-format / hunt-iter / desktop-task-folder）。
默认不要用浏览器；HTTP 用 curl（必要时 --noproxy "*"）。只有 CSRF/双号对比等必须交互时才开 Playwright MCP。
有号面认 ~/.grok/skills/skill/主控调度.md。
约束测试红线认该 SKILL「约束测试红线」（读≤5组；禁写/WebShell/扫描器批量/DoS/内网横向/社工；AK/SK/kube 不自行进业务）。

【目录】
Desktop\{目标}_SRC挖洞\
  资产\        ← 公网 URL + 种子队列.md + covered_hosts + pending_register.md + accounts.md
  js\          ← js/{host}/anon/ 与 js/{host}/{sid}/
  报告\        ← 仅定稿报告 .md（文件名=标题）；禁止塞 .py/.png/过程垃圾
  {短名}_dig\  ← endpoints / endpoints_auth、DONE_anon / DONE_auth、session.cookie

开场建齐 README + 资产/js/报告/{短名}_dig；把 ~/.grok/skills/skill/线程必读.md 整份复制到 {短名}_dig/线程必读.md。
续挖：进既有任务根，禁止另开 2 号夹。先把 ~/.grok/skills/skill/线程必读.md **覆盖复制**到 {短名}_dig/线程必读.md。先读 种子队列 + covered_hosts + 报告/ + pending_register + accounts + dig STATE。肥面已 covered 但无 DONE_auth、accounts 有 cookie → 翻回补登录轨。

【节奏 · 自由跳】
一种子闭环：搜一个种子 → 去重去废去非存活 → 股权闸 → 剩余活面全部挖完 → 才标 done → 立刻下一条。
禁止多种子一次搜完再挖。
禁止问「要不要继续」「其它品牌要不要也挖」「下一步您看」。
优质根域 R 只回灌 pending，本种子剩余活面没挖完不去搜 R。

【队列 · 写死】
种子队列 pending / doing / done / cold 必须与 covered_hosts、本站 §4.3/记废 同步更新。
covered：瘦壳/同闸/无干净口 = 未登录收口即可；肥面干净口 = 两轨都 §4.3 或登录轨 N/A 才写。未登录做完、登录还在排队 → 禁止 covered。不是「curl 过首页 / FOFA 见过」。
doing 无推进不许堆积；换站/换种前把当前条收成 done/cold 或写清挂起原因。
FOFA 限流 / 429 / 820041 / 402：停刷测绘，只挖本种子已入库剩余活面；三账号切换认 dig-scope §2.1.4。池空才允许 crt/JS/已有资产补 host，禁止空等翻页充进度。

【线程 · 流水线双轨】
主控：种子队列、FOFA（仅主控）、派轨、**串行注册/取码/进号 + 身份一枪**、收报告、并短表。
深挖线程：10 条。一人一轨一站。spawn 第一行写死 本轨=未登录 / 本轨=未登录一眼 / 本轨=有会话。**禁止线程发码/注册/登录。**
FOFA / 探活工厂禁止进线程。
空席：① 已有 cookie 且无 DONE_auth → 登录轨（插队；身份能打就写死，打不了 spawn 写待确认）② 本种子 leftover 未登录轨。禁止空 cookie 登录轨占席。禁止瘦壳登录轨。禁止登录墙空壳填满 10 席。10 席不锁成同时 5 站。
一站两线程只在：未登录还没 §4.3 且 cookie 已落地。
主控回合闸：子代理一空立刻补席。禁止用「本波产出/sid 池收口」纯文本结束回合（无 spawn = 停机）。没有可派空席 → 同一回合换种，不是停。开场闸达标 ≠ 可以停。

【有号闭环 · 写死】
细则认 ~/.grok/skills/skill/主控调度.md。
未登录轨只写 DONE_anon 缺号行，禁止改 pending_register、禁止发码。
缺号行：缺号：干净|放弃|无HTTP口；发码=<METHOD URL或无>；提交=<METHOD URL或无>；通道=sms|email|无；sid=…；盾=…；原因=…
登录页 URL 不是干净口。发码/提交 API 才是。要发码 ≠ 放弃。
主控每收 DONE_anon 先跑：python ~/.grok/skills/skill/scripts/pending_from_done.py --root {任务根}
stdout 的 REUSE → 禁止再发码，派登录轨（身份能打就写死，否则待确认）。NEXT → python scripts/auth_flow.py（选号/换 sid 走不通可补脚本）。脚本默认不刷历史 NOHTTP/ABANDON。
有会话 spawn 必贴：本轨=有会话；cookie 路径；身份=有店铺|空户|待确认；curl -b（仍 109 拼 Cookie 头）；先读 anon JS，只补本 sid 新 chunk。禁 logout、禁发码。空户/待确认第一枪仍空 → 打资质，不要对着 109 换 id。
肥面干净口未进号禁止 covered。不同 sid/产品线第一个干净 API 仍要做。

【进站】
先短表开场几枪（对得上再开模块），立刻回本站清单。
本轨=未登录：§4.0 → JS 到 js/{host}/anon/ → 未登录例外+四件套；打开是登录页先找业务 API/发码提交 API；瘦壳一眼；肥面干净口写缺号行禁止 covered。
本轨=有会话：先读 anon JS；cookie GET 后台只补新 chunk 到 js/{host}/{sid}/；有身份对象图，空户打资质/开通。
同闸（业务口同一登录码且未登录例外已点）：四件套收口，sibling 一眼差分，不另开全矩阵。

【价值与类型 · 禁偏科】
力气：未登录他主体 → 认证接管(§4.2.2) → 换 id(§4.2.3) → 有差分面四件套(注入/SSRF/XSS/RCE)。
本站未达 §4.3 禁止拿新词 FOFA 充数。
有差分面必须真打四件套或写 N/A+原因；禁止只交未授权 list 就换站。
中危同一对象先升链再换站。CORS 不挖。仅害自己的 CSRF 不落盘。

【报告】
只认 vuln-report-format 两张表；过 curl/匿名/认钥闸才写。
同根因只交一篇：多 host/preview/QA/同皮写进原篇「涉及接口」或备注，禁止换皮连交。
报告/ 已有同类型同 url → 不另开。高危落盘后本轨 DONE 写拟进/拟补/不进（中危不拟进）。

【开场闸】
10 分钟内必须落盘：种子队列多行、第一个 doing host 的 §4.0 三五行、endpoints 起步。开场闸达标只说明起手合格，**不是停工令**。
若只有 FOFA 条数/探活计数/「已抽 JS」而无清单或差分面 payload → 立刻纠偏回深挖。
有发码/提交 API 却只派下一站、把「要发码」写成放弃、或肥面干净口未进号写入 covered → 立刻纠偏：主控扫 DONE_anon 进号，身份一枪后插登录轨。
空 cookie 仍开登录轨、瘦壳开登录轨、一站起手双开两个子代理 → 立刻纠偏回流水线。
空席未满却只给用户写「本波产出」→ 立刻再 spawn，禁止结束回合。
```

## 锁面（固定站 / URL / 文档 / 清单）

把上面「节奏 · 自由跳」整段换成：

```text
【节奏 · 锁面】
只挖用户给的站/文档/清单及业务流自然带出的同簇 host/path。
禁止未进站就 FOFA 全集团。用户标了优先面先打。同皮登录壳只留 2～3 代表。
禁止问「要不要继续」。
队列与 covered 同步；本簇活面挖完可短报收口。双轨调度仍认有号面（瘦壳不开登录轨）。
```

其余【目录】【线程】【有号闭环】【进站】【价值】【报告】【开场闸】不变；深挖线程仍为 **10**。
