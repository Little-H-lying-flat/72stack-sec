## 有号面：流水线双轨 + 自动注册/登录闭环

> **默认 `挖X`：** 未登录 + 有号都要挖。单位是**轨**，不是「每个网站同时开两个子代理」。  
> **口令：** 发码/提交 **API** 干净 = 主控取码进号 → 身份一枪 → 插登录轨抽本 sid 后台 JS → 有身份对象图，无身份打资质。  
> **禁止**把「要发码」写成放弃。**禁止**收了 DONE 只派下一站。**禁止**肥面干净口未进号就写入 `covered_hosts`。  
> 默认开场：`开场提示词.md` 自由跳段。登录轨优先：同文件「有号优先」。

脚本只跑本目录 `scripts/`。凭据 json 由脚本自己 load。开场把本目录 `线程必读.md` **整份复制**到任务 `{短名}_dig/线程必读.md`（禁止自写漏缺号行 / 漏本轨）。

**口令 → 开哪条轨**

| 用户说 | 开轨 |
|--------|------|
| `挖X` / `继续挖X`（没点名只一边） | 流水线双轨：先未登录，进号成功再插登录轨 |
| `只未登录` / `没号挖` | 只未登录轨 |
| `有号挖` / `只登录` | 登录轨优先。未登录例外在登录轨里点。未进号的肥面只派一眼未登录轨（发码/提交 API + 未登录例外，不跑全矩阵）写 DONE_anon，主控进号后再派登录轨 |

**调度（主控；10 席不锁成同时 5 站）**

活 host **先派未登录轨**（`有号挖` 除外）。然后：

```
瘦壳 / 同闸无新 path / 抠不出干净发码·提交口
  → 未登录收口即 covered，不开登录轨
肥面 + 干净口
  → DONE_anon 缺号行 → 主控串行进号 → 身份一枪 → 插登录轨
一站两线程只在：未登录还没 §4.3 且 cookie 已落地
```

空席只按这个顺序抢（子代理一空立刻补，禁止等用户）：

1. 已有 cookie 且无 `DONE_auth` → 登录轨（插队）。主控能打身份一枪就 spawn 写死 `有店铺|空户`；打不了写 `身份=待确认`，**不要因此空着席位**
2. 本种子 leftover 未登录轨（`有号挖` 未进号肥面只派一眼轨）
3. **禁止**空 cookie 的登录轨占席
4. **禁止**瘦壳登录轨；**禁止**登录墙空壳填满 10 席

**没有可派空席**（本种子活面全 DONE/covered，无 cookie 缺 DONE_auth）→ 本种子标 done，**同一回合**搜下一条 pending / §1.3-C，禁止对用户写收口总结。  
**「收口」**只指单站/单轨 DONE，不是整场停。线程交付后停；**主控交付后必须再派**。

身份一枪：店铺/订单、广告户/计划、公会主号、门店 `merchantPoiId` 这类。`result=1` / 换票成功 **不是**身份。有对象 → 登录轨主业=对象图/换 id。109 / 未开户 / 空户 / 待确认第一枪仍空 → 主业=资质/开通跳步，不要对着 109 换 id。盾或进号失败 2 次 → 登录轨 N/A。

续挖：肥面已在 `covered_hosts` 但无 `DONE_auth`、accounts 里却有 cookie → **翻回补登录轨**，旧 covered 只算未登录收口。开场把 skill `线程必读.md` **覆盖复制**到任务 `{短名}_dig/线程必读.md`。

**spawn 第一行写死本轨。** 一人一轨一站。禁止同一 spawn 里两句主业。

**落盘（两轨禁止互盖）**

| 轨 | DONE | 清单 | JS |
|----|------|------|-----|
| 未登录 | `{dig}/{host}/DONE_anon.md` | `endpoints.md` `matrix.md` | `js/{host}/anon/` |
| 有会话 | `{dig}/{host}/DONE_auth.md` | `endpoints_auth.md` `matrix_auth.md` | `js/{host}/{sid}/`（先读 anon，只补新 chunk） |

旧 `{dig}/{host}/DONE.md` 仍认（缺号/拟进）。缺号行只写 DONE_anon（或旧 DONE）。登录轨写 `身份=有店铺\|空户` + `资质口=`。

**covered**

- 瘦壳 / 同闸一眼 / 无干净口：未登录 §4.3 或记废即可写
- 肥面 + 干净口：两轨都 §4.3，或登录轨已 N/A（盾 / 失败 2 次）才写
- 未登录做完、登录还在排队或身份一枪未出 → **禁止**写 covered

**分工（线程不改共享队）**

| 谁 | 做 | 不做 |
|----|----|------|
| **未登录轨** | `DONE_anon` + 未登录矩阵 + **缺号行**；JS → `anon/` | 发码/注册/登录；写 cookie；写 `DONE_auth` |
| **登录轨** | `DONE_auth` + 有会话矩阵 + 身份行；先读 anon JS | 发码/注册；写缺号行催新号 |
| **主控** | 每收 DONE_anon：**扫缺号行** → upsert `pending_register` → 串行进号或 REUSE → 身份一枪 → 再派空席 | 空 cookie 登录轨；瘦壳登录轨；登录墙空壳填 10 席 |

收单只认缺号行（spawn 回单或 `{dig}/**/DONE_anon.md` / 旧 `DONE.md` 的 `缺号：干净`）。漏写缺号行 = 漏单，主控让补一行再标 covered。线程禁止跑 `profile_get` / `sms_code` / `email_code` / `auth_flow` / `pending_from_done`。

**干净 vs 放弃 vs 无 HTTP 口**

- **干净（必须进队）：** 本摊 **发码或提交的 HTTP API**（`METHOD + 完整 URL`），无滑块/图形/实名/人脸/绑支付。要短信/邮箱码也算干净。
- **登录页 URL 不是干净口。** 只有 SPA/IdP 页、抠不出发码/提交 API → 写 `无 HTTP 口`（默认自由跳不磨 SPA；**有号优先**才开 Playwright MCP 填表+取码）。
- **放弃：** 滑块 / 图形 / 实名 / 身份证 / 人脸 / 绑支付；**别人的 IdP 页本身**。跟回本摊的发码 / 换票 / callback 仍算本摊。
- **「要发码」≠ 放弃。**

**复用先于发码：** `资产/accounts.md` 已有同一 sid / 同一通行证 / 同一账号体系且 cookie 还在 → **禁止再发码**，先身份一枪再派。不为第二号 = 同一体系不注册对照号；**不同 sid / 产品线 / 租户体系的第一个干净 API 仍要做。**

**主控步骤（禁 Read 凭据文件）**

`auth_flow.py` 走不通的选号 / 换 sid / JSON `*_st` 写入 cookie，主控可补一段脚本；禁止把真号/验证码 Read 进对话。禁止用补脚本绕开发码失败 2 次闸。

```
python "{skill_dir}\scripts\pending_from_done.py" --root "{任务根}"
```

stdout：`REUSE` = accounts 里已有 cookie 且尚无 `DONE_auth`，**禁止再发码**，派登录轨（身份能打就写死，否则待确认）。`NEXT` = 发码/提交是 HTTP API 才跑 `auth_flow.py`（登录页 URL 不会进 NEXT）。历史 `NOHTTP` / `ABANDON` 默认不刷 stdout（`--verbose` 才出）。

本场首次通道自检：`sms_code.py --peek` / `email_code.py --peek`。然后：

```
python "{skill_dir}\scripts\auth_flow.py" --channel sms --wait 90 --sender <可选> ^
  --send-url "https://host/api/send" --send-data "mobile={phone}&type=1" ^
  --submit-url "https://host/api/login" --submit-data "mobile={phone}&code={code}" ^
  --save "{dig}\{host}\session.cookie" ^
  --accounts "{任务根}\资产\accounts.md" --target host --sid <体系>
```

邮箱把 `--channel email --wait 120`，body 用 `--send-json` / `--submit-json`，占位 `{email}` / `{email_alias}`。激活链接 `--channel email-link`。`{phone}` `{code}` 由脚本替换，禁止把真号/验证码写进命令行以外的对话。

`auth_flow` 退出 0 → 落 cookie 即可派登录轨。主控能打身份一枪就 spawn 写死；打不了写 `身份=待确认`。退出 3 = 遇盾，pending 标 `abandon`「需人工过盾」，登录轨 N/A。退出 1 计失败，同目标 2 次停，登录轨 N/A。肥面干净口无会话写入 `covered_hosts` = 违规。

失败 2 次停该目标。禁 `/logout` `/signout` `/revoke`。短信只读、不删改、全文不落盘。

**换票票面（身份口径见上面「调度」）**

JSON 回的 `*_st` / `*_at` 必须写入 cookie 文件；`curl -b` 读 Netscape 仍 109 时改拼 `Cookie:` 头。台账「有票无身份」= 空户，登录轨主业仍是资质/开通，不是再开线程换 id。

**进号后抽 JS（登录轨必做；细节 `知识库/js-reverse-guide.md`「登录后懒加载」）**

未登录/C 端包 **不能**拿来打商家/广告主/公会。登录轨 **先读** `js/{host}/anon/`，带着 **该 sid cookie** GET 业务首页，只把新 chunk 补到 `js/{host}/{sid}/`。懒加载 = 主包里已有文件名，点菜单才 fetch → **按表下全，禁止靠点功能当抽干**。路由表 / `authAndRouter` / `import(` 里的 path 没出现在页面也直接打。§4.0 用这批包说清这摊。抽全 JS ≠ 出洞：无业务身份时清单仍建，矩阵停在资质/开通，不要假装订单越权。

## 回灌门闩（P3 · 发现引擎记忆）

> 细则操典：`知识库/回灌闭环.md`。盲区库：`知识库/semantic-blindspots.md`。

**开站：** 派未登录/登录轨之前，主控自己（或 spawn 贴进线程必读已含的 suspects 节）要求：本站 `suspects.md` 威胁模型头必须引用盲区库相关问句（或 `N/A 无关+原因`）。

**收中危+ 报告 / 明确漏报（同回合，禁止攒着）：**

1. 追加 `知识库/semantic-blindspots.md` 一行（类型=命中|漏报；勿写利用步骤/实值）。
2. 若是新根因问句，可并入该文件「高频问句速查」。
3. 同一根因已出现 ≥2 次 → 开 `~/.grok/rules/hunt-iter.md` 评估是否进短表（**禁止**在本 skill 直接改打穿短表手法行）。

**covered 加闸：** 本站若有中危+ 或漏报声明，却无对应盲区库新行 → **禁止**写入 `covered_hosts`。瘦壳 / 无洞收口：回灌勾 `N/A`。

**线程只提醒、主控落盘：** 线程回单写「建议主控回灌：…」即可；改盲区库是主控的活。
