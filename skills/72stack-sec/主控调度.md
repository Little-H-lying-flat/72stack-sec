## 有号面：流水线双轨 + 自动注册/登录闭环

> **默认 `挖X`：** 未登录 + 有号都要挖。单位是**轨**，不是「每个网站同时开两个子代理」。

> **口令：** 发码/提交 **API** 干净 = 主控取码进号 → 身份一枪 → 插登录轨抽本 sid 后台 JS → 有身份对象图，无身份打资质。

> **禁止**把「要发码」写成放弃。**禁止**收了 DONE 只派下一站。**禁止**肥面干净口未进号就 `mark_covered`（禁手写 `covered_hosts`）。**`accounts.md` 空不是跳过理由**：空 = 该跑 `auth_flow` 的信号（全局账密本测试号；短信 ADB、邮箱 IMAP）。禁止写「accounts 空不开登录轨」「无 ready cookie → 不开登录轨」。禁止空 cookie 登录轨占席 = 禁止空 cookie spawn 有会话线程；主控仍必须对无盾干净口串行进号。

> 默认开场：`开场提示词.md` 自由跳段。登录轨优先：同文件「有号优先」。

脚本只跑本目录 `scripts/`。凭据 json 由脚本自己 load。开场把本目录 `线程必读.md` **整份复制**到任务 `{短名}_dig/线程必读.md`（禁止自写漏缺号行 / 漏本轨）。

**口令 → 开哪条轨**

| 用户说 | 开轨 |

|--------|------|

| `挖X` / `继续挖X`（没点名只一边） | 流水线双轨：先未登录，进号成功再插登录轨 |

| `只未登录` / `没号挖` | 只未登录轨 |

| `有号挖` / `只登录` | 登录轨优先。未登录例外在登录轨里点。未进号的肥面只派一眼未登录轨（发码/提交 API + 未登录例外，不跑全矩阵）写 DONE_anon，主控进号后再派登录轨 |

**调度（主控；目标席数默认 10，不锁成同时 5 站）**

活 host **先派未登录轨**（`有号挖` 除外）。然后：

```

瘦壳 / 同闸无新 path / 抠不出干净发码·提交口

  → 未登录收口即 covered，不开登录轨

肥面 + 干净口

  → DONE_anon 缺号行 → 主控串行进号 → 身份一枪 → 插登录轨

一站两线程只在：未登录还没 §4.3 且 cookie 已落地

```

空席只按这个顺序抢（子代理一空立刻补，禁止等用户）：

1. 已有 cookie 且无 `DONE_auth` → 登录轨（插队）。主控能打身份一枪就 spawn 写死 `有店铺|空户`；打不了写 `身份=待确认`，**不要因此空着席位**

2. 本种子 leftover 未登录轨（`有号挖` 未进号肥面只派一眼轨）

3. **禁止**空 cookie 的登录轨占席

4. **禁止**瘦壳登录轨；**禁止**登录墙空壳填满目标席数

**保满：** `doing` < 目标席数且有可派 → 立刻 spawn 到满。leftover pending 填不满空席且本种子可翻页 → 同回合翻页补池再派。禁止 yield 干等最后一条 doing。本种子翻页 ≠ 下种子。

**没有可派空席**（本种子活面全 DONE/covered，无 cookie 缺 DONE_auth）→ 本种子标 done，**同一回合**搜下一条 pending / §1.3-C，禁止对用户写收口总结。

**「收口」**只指单站/单轨 DONE，不是整场停。线程交付后停；**主控交付后必须再派**。

身份一枪（**身份+半径**，P1）：店铺/订单、广告户/计划、公会主号、门店 `merchantPoiId` 这类。`result=1` / 换票成功 **不是**身份。顺带勾 `半径=单户|可换户|疑似跨租户|未知`（凭证绑本号/本店/本租户，还是能摸邻户/下游）。有对象且半径≠未知 → 登录轨主业=对象图/换 id（仍读≤5）。109 / 未开户 / 空户 / 待确认第一枪仍空 / **半径未知** → 主业=资质/开通跳步，**禁止**对着 109 换 id。盾或进号失败 2 次 → 登录轨 N/A。`DONE_auth` 缺 `身份=` 或 `半径=` → 主控退回补字段，禁止 covered。

**空身份禁写（硬闸）：** 释义见 `术语表.md`。主控禁止把空身份会话派成「有店铺」登录轨喷写面；回单须标「空身份禁写」停枪，否则退回、禁 covered。

**未授权写（硬闸）：** 空会话 `POST/PUT/PATCH/DELETE` 只要打到 Controller/落库层，一律记未授权写（约束失败、业务回 false 也算）。禁止当普通 IDOR 或探测噪音丢掉。covered 前须有写面探针结论或 `写面=N/A+原因`。

续挖：肥面已在 `covered_hosts` 但无 `DONE_auth`、accounts 里却有 cookie → **翻回补登录轨**，旧 covered 只算未登录收口。开场把 skill `线程必读.md` **覆盖复制**到任务 `{短名}_dig/线程必读.md`。

**spawn 第一行写死本轨。** 一人一轨一站。禁止同一 spawn 里两句主业。

**干净 vs 放弃 vs 无 HTTP 口**

- **干净（必须进队）：** 本摊 **发码或提交的 HTTP API**（`METHOD + 完整 URL`），无滑块/图形/实名/人脸/绑支付。要短信/邮箱码也算干净。

- **登录页 URL 不是干净口。** 只有 SPA/IdP 页、抠不出发码/提交 API → 写 `无 HTTP 口`（默认自由跳不磨 SPA；**有号优先**才开 Playwright MCP 填表+取码）。

- **放弃：** 滑块 / 图形 / 实名 / 身份证 / 人脸 / 绑支付；**别人的 IdP 页本身**。跟回本摊的发码 / 换票 / callback 仍算本摊。

- **「要发码」≠ 放弃。**

**复用先于发码：** `资产/accounts.md` 已有同一 sid / 同一通行证 / 同一账号体系且 cookie 还在 → **禁止再发码**，先身份一枪再派。不为第二号 = 同一体系不注册对照号；**不同 sid / 产品线 / 租户体系的第一个干净 API 仍要做。**

**主控步骤（禁 Read 凭据文件）**

`auth_flow.py` 走不通的选号 / 换 sid / JSON `*_st` 写入 cookie，主控可补一段脚本；禁止把真号/验证码 Read 进对话。禁止用补脚本绕开发码失败 2 次闸。

```

python "{skill_dir}\scripts\pending_from_done.py" --root "{任务根}"

```

stdout：`REUSE` = accounts 里已有 cookie 且尚无 `DONE_auth`，**禁止再发码**，派登录轨（身份能打就写死，否则待确认）。`NEXT` = 发码/提交是 HTTP API 才跑 `auth_flow.py`（登录页 URL 不会进 NEXT）。历史 `NOHTTP` / `ABANDON` 默认不刷 stdout（`--verbose` 才出）。

本场首次通道自检：`sms_code.py --peek` / `email_code.py --peek`。然后：

```

python "{skill_dir}\scripts\auth_flow.py" --channel sms --wait 90 --sender <可选> ^

  --send-url "https://host/api/send" --send-data "mobile={phone}&type=1" ^

  --submit-url "https://host/api/login" --submit-data "mobile={phone}&code={code}" ^

  --save "{dig}\{host}\session.cookie" ^

  --root "{任务根}" --login-url "https://host/login" --accounts "{任务根}\资产\accounts.md" --target host --sid <体系>
```
