# 打后台链路模式库

每条链报告时填写：前置条件 / 步骤 / 最终后台能力 / 状态。

## Chain A — 无鉴权直达（最常见通用链）

```
网络可达管理面 → 匿名访问 UI 与 /api/* → 完整后台能力
```

信号：无 login 中间件；`0.0.0.0`；管理 API 200。

## Chain B — 配置/密钥泄露扩权

```
匿名读配置 → API Key / DB / VM / 云凭据 → 横向或接管依赖服务
```

信号：`/api/system/config`、`/actuator/env`、`.env` 暴露。

## Chain C — SSRF 打本机/内网管理面

```
URL 重放/代理接口 → http://127.0.0.1:<admin|cdp|redis|docker> → 控服务或读机密
```

信号：用户 URL + 服务端 fetch +（可选）body 回显。

## Chain D — 存储 XSS → 管理员

```
可写字段入库 → 管理员打开列表/详情 → JS 执行 → 借会话调管理 API
```

注意：无会话模型时降级，但仍记 G31。

属性注入专项：

```
text 用了 escape，但 data-id="${user}" 未编码 → 仍可 XSS
```

## Chain E — 配置写 + 进程启动 = 间接 RCE

```
写可执行路径/脚本入口到配置 → 调用 start 服务 → Popen(可控路径)
```

条件：路径需存在或可落盘。状态常为 Likely。

## Chain F — 组合放大

```
A（无鉴权）+ C（SSRF 本机旁路端口）+ B（密钥）
→ 外网入口即可完成内网横移与凭据收割
```

## 报告示例

```markdown
### Chain-1（Confirmed）
- 模式：A
- 前置：实例监听 0.0.0.0:5001 且无鉴权
- 步骤：访问 / → 调用 /api/system/config 与业务 API
- 能力：读写项目/流量/配置，启停扫描
- 修复：鉴权 + 默认 127.0.0.1
```
