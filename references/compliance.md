# 合规与合法红线

在提交任何 finding 前,本文件必须被读取并逐条比对。任一项不通过 → finding 撤回 / 重测。

---

## ❌ 绝对禁止

- **出 scope 资产**:目标不在 Phase 1 已确认的 in-scope 列表 → 立即停手 + 自报告给项目方。
- **取走他人 PII**:仅证明"可访问",不实际下载 / 转储他人数据。已不慎获取的立即销毁并记录。
- **持续负载 / DoS / 大流量**:仅发 1–3 个 PoC 包证明可触发,严禁压测 / 自动化连发。
- **修改他人数据**:即使发现可写也只在**自己控制的对象**上验证。不准对他人订单 / 账户 / 内容 / 资料做写操作。
- **生产钓鱼 / 社工**:不做。
- **未复现猜测**:不得提交"理论上可能存在"的 finding。必须有 HTTP 包 / 截图 / 视频证据。
- **拖第三方 SaaS**:出 scope 的云资产、CDN、托管服务一律不测。
- **横向移动到内网**:即使从 SSRF / RCE 触达内网,仅证明"可达",不进一步横向。

---

## ✅ 必做

- 测试 header 自标:`X-Bug-Bounty: <你的 handle>` 或项目要求的标记。
- 越权 / IDOR 用**自己控制的两个账号**自演,不要拿真实用户 ID 试探。
- SSRF / XXE / RCE 外带用**自己的 OOB 域名**(interactsh / 自建 DNSLog),不要用公共 / 他人 DNSLog。
- 提交前用 `references/templates/report-submission.md` 自查三段式结构是否完整。
- 提交前对照 CVSS 4.0 vector 给评级,不要凭感觉写 High/Critical。
- 提交后保留所有原始包 + 截图 ≥ disclosure window 结束。

---

## ☁️ 云授权项目增补

涉及云资产（对象存储 / K8s / 云凭据 / 云控制面）时,在通用红线之上追加:

- **凭据最小动作**:验证 AK/STS 有效性只发只读调用(`get-caller-identity` 级);权限枚举限速 ≤10 QPS。
- **影响证明即停**:可读 bucket 取 1 条脱敏样本;etcd / K8s API 读 1–2 个 key;不整桶同步、不递归导出、不拉业务镜像。
- **写验证自命名**:对象存储写权限只用 `security-test-<时间戳>` 新对象验证,验后即删并留删除证据,绝不覆盖既有对象。
- **测试资源清理**:创建的对象 / Pod / 函数在提交报告前删除,报告附清理清单。
- **不用目标凭据触达第三方**:用目标 AK 调任何第三方服务视为数据外带,直接违规。
- **etcd / K8s 禁实际接管演示**:匿名列资源用 SSAR / 匿名 200 JSON 作证据,不建 Pod / 不部署工作负载。

细则见 `playbooks/cloud/00-index.md` §2(scope 增量)与 §6(云红线)。

## ⚖️ 国内法律边界(常识性提醒,以最新法规与司法实践为准,非法律意见)

- **授权是法律边界**:刑法第 285 / 286 条(非法获取计算机信息系统数据 / 破坏系统)的构成不以外传为前提——**拿到即获取**。scope 外资产即使技术可达也不进,公告/scope 页截图存档到 `work/<slug>/scope.md`,这是"合法"二字的锚。
- **他人 PII**:触达即停 + 不下载 + 不留存 + 报告脱敏(个人信息保护法口径);测试账号一律用自己身份注册——自己授权自己。
- **业务数据**:不批量导出(数据安全法口径);证据取"足以证明能读"的最小样本,与 03-evidence-discipline 一致。
- **破坏性动作零容忍**:删库 / 篡改页面 / 影响可用性(如压测)直接越过刑事红线,与"漏洞多严重"无关。
- **提交渠道**:CNVD / CNNVD / 平台各自的提交协议不同,涉关键信息基础设施的目标严守其公告禁测项。

## 撤回触发条件

下列任一情况立即向项目方撤回 finding:
- 事后发现资产其实 out-of-scope
- 复现步骤中包含取走的他人 PII
- PoC 流量超过 1–3 个包还在继续
- 影响范围被夸大(评级 vs 实际可证明影响不符)

---

## 与 Phase 4 的边界

Phase 4 的 playbook 中每个攻击章节都有自己的"不要做的事"小节。本文件是**通用红线**,playbook 内的限制是**类型特定红线**,二者都要遵守。冲突时取更严格的一项。
